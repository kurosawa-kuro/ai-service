## 役割分担（現契約での使い分け）

- **設計・レビュー・重い実装** → Claude Code（Claude Pro）。**Fable 5 は従量クレジット課金になった**ため、重い Fable タスクは従量コストを見て選別する。
- **repo 実装・docs 同期・CLI エージェント** → Codex（ChatGPT Pro）。
- **IDE 内の補完・軽い修正** → GitHub Copilot Pro。
- **AI IDE 体験の試用** → Cursor Hobby（無料枠）。有料化判断は保留。

## 見直しの観点（コスト最適化）

- **Claude Pro ($20)**: 8/7 予定だった降格判断は **2026-08-04 に前倒しで実施済み**（Max 5x → Pro）。以降の観点は2つ。
  1. **Pro の枠（5時間窓＋週次上限）が実作業量に足りるか**。逼迫が常態化するなら Max 5x へ戻す判断材料。Cowork Web / モバイルが Max 先行な点も戻す側の材料。
  2. **Fable 5 の従量クレジット実績**（Pro は枠外、$10/M 入力・$50/M 出力）。従量が月 $80 を超え続けるなら Max 5x ($100・週次上限の50%まで包含) の方が安い。実測方法は [30_評価/](../30_評価/)。
- **ChatGPT Pro ($100)**: 唯一残ったハイプラン（Claude 側降格済みのため原則上の降格義務はなくなり、以降は純コスト判断）。Codex メイン。Codex 中心で quota が余るなら Plus ($20) で足りる可能性。逆に quota 逼迫なら Pro $200。
  - **2026-07-20 更新（降格の論拠が強まった）**: **GPT-5.6 Sol は Plus $20 で到達可能**（Medium 以上の effort 設定経由。既定は GPT-5.5 Instant のまま）。したがって「最上位モデルに触れるために Pro $100 が要る」という維持論拠は成立しない。
    - ただし最高品質の **Sol Pro は Pro / Enterprise 限定**。「最上位」に Sol Pro を含めるなら Plus では到達できず、判断が反転する。
    - ChatGPT Work は Pro から展開・Plus 拡大予告（2026-07-10・未検証）。
    - 残る維持論拠は**モデル到達性ではなく Codex quota の量**のみ。実使用量次第。
- **重複の点検**: Claude Code / Codex / Copilot で**コーディング支援が三重**。実作業でどれをどれだけ使うかを [30_評価/](../30_評価/) で計測し、被りが大きければ 1つを格下げ/解約する候補。
- **合計 $130/月（≈¥20,150）**。次の削減余地は ChatGPT Pro → Plus の $80。用途量の実測（`30_評価/`）で「定額サブスク vs BYO-key 従量」の損益分岐を出すと最適化しやすい。目標形は第一理想 [03_将来方針.md](03_将来方針.md)（$60〜/月）、それが安定しない場合は第二理想 [02_AIフロンティア・バーベル戦略.md](<02_AIフロンティア・バーベル戦略.md>)。
