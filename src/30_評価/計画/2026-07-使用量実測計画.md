# 使用量実測計画（8/7 降格判断向け）

> 目的: **2026-08-07 の契約判断**（Claude と ChatGPT のどちらをハイプラン枠に残すか）に必要な数字を取る。
> 起点: [10_契約/01_現在の契約.md](../../10_契約/01_現在の契約.md) の「原則整合ステータス：⚠️ 違反中」。
> 作成日: 2026-07-20 ／ 残り日数: 約18日

## なぜ必要か

現契約は Claude Max 20x ($200) ＋ ChatGPT Pro ($100) の**ハイプラン2枚**で絶対原則に違反している。
解消には片側を降格するしかないが、**どちらを残すかを決める実測データが存在しない**。

既存の評価計画4件はいずれも品質評価（差分品質・安全性・再現性）が軸で、
**使用量・コストの軸を持たない**。本計画がその欠落を埋める。

## 計測できるもの／できないもの

**ai-gateway では取れない。** Claude Code / Codex はサブスク認証で provider へ直接接続し
gateway を通らないため `ai_runs` に行が立たない。単位も非互換（枠＝離散カウンタ／gateway＝トークン×単価）。

| 対象 | 取得元 | 自動化 |
|---|---|---|
| **Claude 枠の消費率**（一次ソース） | `claude.ai` → Settings > Usage。5時間窓バー・週次上限バー・次回リセット時刻 | ✗ 手動（スクショ） |
| Claude Code のトークン内訳 | `ccusage`（`npx ccusage`）。`~/.claude/projects/*.jsonl` を集計 | ✅ 可 |
| Claude Code のセッション内実績 | `/usage`（Pro/Max では使用量バー付き。`d`/`w` で 24時間/7日 切替） | △ 対話内 |
| **Codex の quota 消費**（一次ソース） | `chatgpt.com/codex/cloud/settings/analytics`。5時間窓・週次上限・PAYG クレジット | ✗ 手動（スクショ） |
| Codex のセッション内実績 | Codex CLI 内で `/status` | △ 対話内 |
| Open WebUI 経由の API 従量 | ai-gateway `ai_runs`（本番稼働中） | ✅ 可 |

### 注意点

- `/usage` と `ccusage` は **ローカルマシンの履歴のみ**。Mac mini と Linux 端末で使い分けている場合、
  片方だけでは過少計上になる。**枠の消費率は必ず claude.ai 側の画面を一次ソースにする。**
- Anthropic Console (`platform.claude.com`) は API 課金用。サブスク枠は表示されない可能性が高い（未確認）。

## 測る指標（降格判断に効くものだけ）

| # | 指標 | なぜ要るか |
|---|---|---|
| 1 | **週次上限の消費率**（%） | 50% 未満が続くなら 20x → 5x、さらに下位も検討可能 |
| 2 | **上限到達回数**（週あたり） | 0 回が続けば降格可。週2〜3回なら現状維持の論拠 |
| 3 | **Fable 5 の利用頻度・トークン量** | Pro では従量クレジット（$10/$50 per M）。月額換算して Max 5x $100 と比較 |
| 4 | **Codex の週次 quota 消費率** | Pro $100 → Plus $20 に落とせるかの唯一の論拠（モデル到達性は Plus で足りると確定済み） |

## 手順

### 毎日（5分）

1. `claude.ai` → Settings > Usage をスクショ。5時間窓と週次上限の % を記録
2. `chatgpt.com/codex/cloud/settings/analytics` をスクショ。同上
3. `npx ccusage --json` を実行し出力を保存（Claude Code のトークン内訳・モデル別）
4. 上限に到達した場合は**日時と作業内容**を記録（これが最も重要なデータ）

### 週次（8/7 までに3回）

`ログ/2026-07-使用量実測.md` に週次サマリを追記する。書式は [README.md](../README.md) の項目7つに従う。

### 8/7 の判断

```text
Claude 週次消費率 < 50% かつ 上限到達 0回
  → Max 20x は過剰。5x へ。さらに Fable 5 実績が月$80未満なら Pro+従量も検討

Codex 週次消費率 < 20%（Pro $100 = Plus $20 の5倍quota）
  → Plus $20 で足りる。ChatGPT を降格しハイプラン枠は Claude に寄せる

両方とも余裕あり
  → 第一理想（03_将来方針）へ直行できる可能性
```

**どちらを降格しても絶対原則は満たせる**が、片方は必ず降格する（現状は違反中）。
