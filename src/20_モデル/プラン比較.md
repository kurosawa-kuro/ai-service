## プラン詳細（有料の主力4系統）

### Cursor（AI IDE）

- **Hobby $0 / Pro $20 / Pro+ $60 / Ultra $200**。Hobby は Agent / Chat / Tab の試用、有料個人プランは Tab 無制限と拡大された Agent 枠。
- **Cursor Models**（Grok 4.6 / 4.5 / Composer 2.5）と **Other Models** の2プール。利用モデルで消費が変わり、超過時は追加従量またはプラン変更を選ぶ。固定の「Auto 無制限」「他社モデル一律 $20 分」という旧説明は撤回。[モデル・料金](https://cursor.com/docs/models-and-pricing)
- 法人は Teams Standard $40 / Premium $120/席。Teams / Enterprise の他社モデルには **Cursor Token Rate $0.25 / 1M tokens** を追加（包含枠・超過・BYOK に適用）。[追加レート](https://cursor.com/help/models-and-usage/token-rate)
- Origin は有料プラン向け初期 beta。iOS アプリも有料対象プランで、Android アプリは計画中。無料枠だけで全実行面を評価できるわけではない。[サービス台帳](../21_サービス/cursor.md)

### GitHub Copilot（補完＋エージェント）

- **Free $0**: 補完 2,000/月、制限付き AI credits、Auto モデル選択。CLI も対象。
- 包含 credits は **Pro: 基本1,000＋Flex500 / Pro+: 基本3,900＋Flex3,100 / Max: 基本10,000＋Flex10,000**。Flex は変動するため、現在の合計を恒久保証値にしない。
- **1 credit=$0.01**。毎月1日 UTC にリセットし、繰越なし。有料補完は credits を消費せず、Chat / CLI / cloud agent 等の使用量を同じ枠で精算する。[課金詳細](https://docs.github.com/en/copilot/concepts/billing/usage-based-billing-for-individuals)
- Business $19/席（1,900 credits）、Enterprise $39/席（3,900 credits）。[プラン](https://docs.github.com/en/copilot/get-started/plans)
- **Astra は Pro+ / Max / Business / Enterprise 対象**（9/4、段階展開）。Pro $10 のモデル到達性と混同しない。[公式発表](https://github.blog/changelog/2026-09-04-gpt-6-astra-is-generally-available-in-github-copilot/)

### Claude Pro / Max（＝ Claude Code の土台）

- **Pro $20 / Max 5x $100 / Max 20x $200** に Claude Code を含む。Pro は年払い $200/年。チャットと Code が同じ使用量を共有し、5時間枠と週次上限がある。
- **Fable 5 / 5.1**: Max / Team Premium は週次枠の最大50%まで包含。Pro / Team Standard は初回から従量クレジット。50%は既存週次枠の内数で、追加枠ではない。[プラン別条件](https://support.claude.com/en/articles/15424964-claude-fable-models-on-your-plan)
- **Fable 5.1 は9/1公開**。API 入力 $10 / 出力 $50 / cache read $0.25（各1M tokens）。**Sonnet 5 は入力 $2 / 出力 $10 が標準価格**となり、9/1に $3 / $15 へ上がる予定は撤回された。[公式リリースノート](https://platform.claude.com/docs/en/release-notes/overview)
- 既定モデルは Pro / Team Standard が Sonnet 5、Max / Team Premium 等が Opus 5（組織・個別設定で変わる）。Fable を選ぶ際は、包含枠か従量かを確認する。[モデル設定](https://code.claude.com/docs/en/model-config)
- 旧稿の「週次上限が恒久的に縮小した」等の過去プロモ解釈は、現行上限の数値根拠に使わない。現在の Usage 画面と実測を基準にする。

### ChatGPT Plus / Pro（＝ Codex CLI/IDE の土台）

- Free / Go / Plus / Pro 等に Codex を含む。**Go $8 / Plus $20 / Pro 5x $100 / Pro 20x $200**。Pro の倍率は Plus 比で、モデルの消費量や別の制限もある。
- **Codex と ChatGPT Work は同じ使用量・credits を共有**。Work 側の処理もコーディング枠の見積もりに含める。[料金](https://learn.chatgpt.com/docs/pricing)
- Codex のモデルは **GPT-6 Astra / GPT-5.6 Sol・Terra・Luna**。9/4の CLI 0.153.4 では未設定時の同梱既定モデルが Astra になった。実際の選択肢はアカウント・管理設定・実行面に依存する。[モデル](https://learn.chatgpt.com/docs/models) / [changelog](https://learn.chatgpt.com/docs/changelog)
- **ChatGPT サブスクと API は別課金**。API キーは CLI / SDK / IDE で利用できるが、GitHub 自動レビュー等のクラウド機能は含まない。[料金・認証別の範囲](https://learn.chatgpt.com/docs/pricing)
- Business は月払い $25/席、年払い $20/席/月・2人以上。モバイルの Remote は接続先 PC の稼働とアカウント側の提供条件も必要。[Remote](https://learn.chatgpt.com/docs/remote)

## BYO-key 系（ソフト無料・コストはモデル API）
- **Cline / Aider / OpenCode**: ソフトウェアは無料。実コストは呼ぶモデルの API 従量（直接 or OpenRouter 経由）。プラン契約は不要で、モデル選択とトークン量でコストが決まる。
- **Codex CLI**: CLI 本体は無料だが、ChatGPT の包含枠 / credits か OpenAI API key を消費。

## 使い分けの要点（コスト観点）
- **少額の月額から比較するなら**: Claude Code=Pro、Codex=Free / Go / Plus、Copilot=Free / Pro、Cursor=Hobby / Pro。必要な機能・モデルと包含枠内の完了率を先に測る。
- **モデルを自由に選びトークン単価で払うなら**: Cline / Aider / OpenCode ＋ BYO key（OpenRouter でルーティング）。
- Claude / ChatGPT は**使用量共有・上限あり**。Copilot の Flex 枠と Cursor のプールも無制限ではない。高額プランへの変更は追加課金・手戻り・処理量の実測で判断する。
