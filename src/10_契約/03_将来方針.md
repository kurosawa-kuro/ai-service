# 将来方針

> AI コーディングサービス契約の**第一理想**。現状は [01_現在の契約.md](01_現在の契約.md)、高額プランが必要になった場合の退避先は [02_AIフロンティア・バーベル戦略.md](<02_AIフロンティア・バーベル戦略.md>) を参照。
>
> **最終更新: 2026-10-12**。料金は月払い・税別、`$1 = ¥155` の概算。実際の請求額が分かる契約は請求額を優先する。

## 結論

現在の **Claude・ChatGPT・Cursorを標準プランで持つ構成（約¥9,100/月）**を基準とする。

利用枠が足りなくなっても、3社を一度に上げない。まず超過分を従量で処理し、同じサービスの不足が継続したときだけ、そのサービスを1か月アップグレードする。

現時点の暫定第一候補は **Cursor Pro+**。理由は、現在のCursor枠を使い切っており、他の2社を上げるより追加固定費が小さいため。ただし、実際の主力がCodexなら **ChatGPT Pro 100**、Claude Codeなら **Claude Max 5x**を優先する。

```text
標準3契約を維持
  ↓ 同じ枠不足が繰り返す
従量課金で1か月計測
  ↓ 従量額・中断損失がプラン差額を上回る
該当する1社だけアップグレード
  ↓ 1か月後に効果を評価
継続または標準プランへ戻す
```

## 守る原則

- **フロンティアのハイプランを複数契約しない。** 詳細は [README.md](README.md)。
- モデルの格ではなく、実作業のボトルネックへ投資する。
- 「枠を使い切った」だけで上げず、そのサービスで続けたい作業が止まったかを見る。
- 固定費を上げる前に、従量課金の実績と作業中断の頻度を確認する。
- 高額化は1か月単位で試し、惰性で維持しない。

## 強化候補

| 強化対象 | 変更 | 新しい合計 | 現状からの増額 | 選ぶ条件 |
|---|---|---:|---:|---|
| **Cursor** | Pro $20 → Pro+ $60 | **約¥15,300** | **+約¥6,200** | Cursorを主なIDE・エージェントとして使い続けたい |
| **ChatGPT** | Basic 約¥3,000 → Pro 100 $100 | **約¥21,600** | **+約¥12,500** | Codexが主力で、枠不足により作業が頻繁に止まる |
| **Claude** | ベーシック 約¥3,000 → Max 5x $100 | **約¥21,600** | **+約¥12,500** | Claude Codeを主力へ戻し、標準枠では足りない |

計算:

- Cursor強化: Claude ¥3,000 + ChatGPT ¥3,000 + Cursor ¥9,300
- ChatGPT強化: Claude ¥3,000 + ChatGPT ¥15,500 + Cursor ¥3,100
- Claude強化: Claude ¥15,500 + ChatGPT ¥3,000 + Cursor ¥3,100

### 1. Cursor Pro+

最小の追加固定費で、現在枯渇しているCursorを直接強化できる。複数社のモデルを同じIDEから使う運用とも相性がよい。

ただし、Proの超過分が少額ならPro+より従量課金の方が安い。**毎月の超過額がPro+との差額 $40 に近づく、または枠切れによる作業移動が常態化した場合**にアップグレードする。

### 2. ChatGPT Pro 100

設計・実装・分析をCodex中心で進めるなら、投資先として最も整合する。

ただし、現在の観測値は5時間枠76%であり、まだ不足は確定していない。Codexがリセット待ちで頻繁に止まる、または追加クレジットが毎月のプラン差額に近づく場合に候補へ上げる。

### 3. Claude Max 5x

Claude Codeを長時間使う体制へ戻す場合の候補。Pro相当より大きい利用枠に加え、Maxには月次APIクレジットがある。

一方、既存のDeepSeek API残高があるため、APIクレジットを得ること自体はアップグレード理由にしない。**Claude Codeを主力として使うか**で判断する。

## 判断表

| 実際に困っていること | 最初に試すこと | 改善しなければ |
|---|---|---|
| Cursorが月途中で止まる | Proのまま超過従量を計測 | Cursor Pro+を1か月試す |
| Codexが何度も上限に達する | 追加クレジットと停止時間を記録 | ChatGPT Pro 100を1か月試す |
| Claude Codeが何度も上限に達する | 使用量クレジットと停止時間を記録 | Claude Max 5xを1か月試す |
| 3サービスとも少しずつ足りない | 作業ごとの主担当を1社に寄せる | 主担当だけを強化する |
| 高額化しても利用量が増えない | 次回更新前に標準へ戻す | 現行の約¥9,100構成を維持 |

## 1か月の検証手順

### 変更前

1. 枠を使い切った日とリセット日を記録する。
2. 枠切れで中断・移動した作業を記録する。
3. 超過従量または追加クレジットの金額を記録する。
4. 本来その作業に使いたかったサービスを記録する。

### 変更後

1. 強化したサービスで完了した作業数を確認する。
2. 枠切れによる中断が減ったか確認する。
3. 他サービスの使用量が減ったか確認する。
4. 増額分に見合う時間短縮がなければ、次回更新前に戻す。

記録先は [30_評価/](../30_評価/) とする。

## 採用条件と撤退条件

アップグレードは、次のどちらかを満たす場合に採用する。

- 毎月の超過従量・追加クレジットが、アップグレード差額に近い。
- 枠切れによる中断や別ツールへの移動が、差額以上の時間的損失を生んでいる。

次のどれかに当てはまれば標準プランへ戻す。

- 強化した枠を十分に使わなかった。
- 主力ツールが別サービスへ移った。
- 従量課金の方が安かった。
- 2社目のハイプランが必要になった。絶対原則を守り、どちらか1社へ絞る。
