## 2026-10-20 決定（トレード研究の1か月）

この1か月の支出先は、開発効率でもアプリ開発能力でもない。黒澤OSで「誰かの失敗を捉えたのに、自分には利益が残らなかった」原因を識別できるか、という実験に使う。

[03_将来方針.md](03_将来方針.md) の「開発のボトルネックへ投資する」「暫定第一候補は Cursor Pro+」は、この1か月には適用しない。03 の目標形自体は変えない。

モデルのトレード研究能力を直接比較した実証ではない。公表能力と、今の研究課題からの暫定評価。本人の確度は約60%。

### 順序

2か月目が無い可能性を前提にする。先に OpenAI Pro を取る。

| 期間 | 契約 | 期待する役割 |
|---|---|---|
| 1か月目 | **OpenAI Pro 100**（GPT-6 Pro） | 仮説の反証、失敗の発生構造、利益が残らない原因 |
| 2か月目（無くてよい） | **Claude Max 5x**（Fable 5.1） | 複雑な環境認識の整理、新しい研究視点 |
| 通期 | Claude は Pro $20 のまま（1か月目） | 標準枠の反証役。Max には上げない |

1か月で利益改善につながる研究成果が残るなら、Claude Max を契約せずに終えてよい。

OpenAI を先にする理由は、今必要なのが研究領域を広げることより、既存の優位性を利益に変換できていない原因を突き止めることだから。Claude に期待するのは、長い時間的文脈の環境認識と、新しい研究視点。説明が説得的でも、成績改善の判断に届かなければ価値は限定的。これは OpenAI にも同じ。

比較から外したもの:

- アプリ開発能力（API クレジットを含む）
- 「大量データの統計処理だけなら OpenAI」という限定。OpenAI に期待するのは、統計処理とは別の、仮説を否定する推論

### 1か月で残す成果

優先は次の3つ。

| 優先 | 研究テーマ | 目的 |
|---|---|---|
| P0 | CASE2 が伸びない構造 | 無駄な損失を減らす |
| P0 | 利益を残せない決済構造 | 期待値の改善 |
| P1 | 縦の値幅・横の時間幅 | 環境認識の改善 |

注目するのは、エントリー後に一度は +0.5R に達し、その後伸びずに終わるケース。次の3つに分ける。

1. エントリー時点で、伸びない構造を識別できた。
2. エントリー後の状態変化で識別できた。
3. 識別不可能で、小利益の確保が合理的だった。

3番目も成果である。無い優位性を探し続けずに済む。

出口は、除外で減った損失と、同時に失った右尾利益を比べ、費用控除後の週間・月間期待値が改善するかを見る。勝率の改善を目的にしない。

終了時に残すもの:

- 利益が残らない CASE2 の分類と、その検証結果
- 環境認識で有効だった特徴量と、不要だった特徴量
- 損失削減と右尾の維持が両立したかの検証結果
- 反証条件付きの、次の研究計画

検証契約は維持する。探索は 30 イベント以上。採用・棄却は各主要比較群 50 イベント以上。標本が足りなければ結果は「未確定」。モデルが提案した仮説を、この検証なしに実戦ルールへ上げない。既存の CASE2 を別の言葉で説明しただけのものも、新しい条件として採用しない。

両モデルを比べる予備評価をするなら、結果を隠した過去の CASE2 を 20〜30 例渡し、「利益を残せない理由」と「その仮説を何で否定できるか」を出させる。その後に価格推移を開示する。これは研究適性の予備評価であり、売買条件の優位性を確定する標本ではない。上がるか下がるかを当てさせる比較にはしない。

### OpenAI Pro の使い方

公式（2026-10-20 確認）: [Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers) に Pro 100 は月 $100。 [GPT-6 Pro](https://help.openai.com/en/articles/20001354-gpt-56-and-gpt-6-pro-in-chatgpt) は Pro $100 で使える。Pro $100 では **GPT-6 Pro と GPT-5.6 Sol Pro が同一の週次枠**を共有する。枠を使い切っても契約は止まらず、別モデルかリセット待ちになる。ChatGPT Work と Codex の枠は、この Chat の Pro 枠とは別。

「週50通、約4週で200通」は公式ヘルプの本文には数値が無く、本人見立て。契約後に画面の残数で確認する。

通常モデルで論点を整理し、重要な仮説の検討と反証に GPT-6 Pro を使う。

Claude の反証の質、裁量判断の改善、実現損益への寄与が OpenAI を上回ったら、この「先に OpenAI」は撤回する。

### Cursor Pro+ は自動更新を止める

理由は、予算を開発効率ではなく黒澤OSの研究へ寄せるため。

公式（2026-10-20 確認）:

- 今の Pro+ $60 は **legacy**。既存契約者は、変更か解約まで価格と機能が続く。[Legacy plans](https://cursor.com/docs/account/pricing/legacy-cursor-plans)
- 解約したあとに $60 へ戻る経路は無い。新規は The X Subscription。Pro+ に近い段は **Super $100**。近いだけで同一ではない。新プランは他社モデルの包含枠を持たず、Premium 以上では API 定価をプリペイドから払う。[Pricing and plans](https://cursor.com/help/account-and-billing/pricing)
- 解約しても、現在の請求期間が終わるまでは有料機能が残る。更新の24時間以上前に止める（[料金ページ](https://cursor.com/pricing) の表記）。

2026-10-12 の使用量リセット予定（10/27）は、請求期間の終了日とは別。終了日は Cursor の請求画面で確認する。

## 役割分担（この1か月）

- **黒澤OSの反証・失敗構造** → ChatGPT Pro の GPT-6 Pro。週次の共有枠を反証に使う。
- **標準枠での壁打ち・環境認識の下書き** → Claude Pro。Max の Fable 枠は、この1か月は買わない。
- **repo 実装** → Codex は Pro の Work/Codex 枠（Chat の Pro 週次枠とは別）。開発のために Pro を買ったわけではない。
- **IDE** → 請求期間が終わるまで Cursor Pro+。終了後は有料プランなし。$60 への再契約はできない。

## 見直しの観点（1か月後）

次回更新の前に、次のどれかへ寄せる。

- Pro を継続する。研究成果が、追加の約¥3,100 を超えて残っている。
- Pro を落とし、Claude Max 5x へ1か月移す。ハイプランは入れ替えで1枚。
- 両方を標準（Claude Pro $20 ＋ ChatGPT Plus $20、Cursor は戻さない）へ戻す。有益な研究成果が無ければ、高額プランは維持しない。

残った成果は「新しい手法」ではなく、既存の黒澤OSで利益が残らない理由を、前より正確に識別できたかどうかで見る。
