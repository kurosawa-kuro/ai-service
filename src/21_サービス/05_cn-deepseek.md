| 軸 | 評価 | 根拠 |

## 管轄・データ規約（最重要・要注意）

| 項目 | 内容 |
|---|---|
| 法域 | **中華人民共和国** |
| データ保存先 | **中国国内のサーバー**（プライバシーポリシーに明記） |
| 学習利用 | 収集データを機械学習モデル・アルゴリズムの訓練に**利用しうる**と明記 |
| オプトアウト | ポリシー上「モデル訓練目的の個人データ利用を拒否する権利」の記載あり |
| **API 入力の学習除外** | ⚠️ **公式に明言されていない（未確認）** |

> **これが本サービス最大のリスク項目。**
> OpenAI / Anthropic が持つような「API 経由の入力は学習に使わない」という明示的な除外条項を確認できなかった。
> **業務コード・顧客データ・秘匿情報を渡す用途では使わない。**
> 該当する処理は [22_用途/ローカル秘匿.md](../22_用途/ローカル秘匿.md) の判断ルールに従い、
> ローカル（Ollama）か、明示的な非学習条項を持つプロバイダへ回す。

出典: [プライバシーポリシー](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html)（2026-02-10 更新）

## ハーネス適性

- ワークフロー組み込み: **高**
- 接続方式: OpenAI 互換 API / **Anthropic 互換 API** / OpenRouter / LiteLLM
- **Anthropic API 互換エンドポイント** `https://api.deepseek.com/anthropic` を公式提供。
  `claude-opus*` → V4-Pro、`claude-sonnet*` / `claude-haiku*` → V4-Flash にマップされ、
  **Claude Code のバックエンドに直接差せる**（出典: [公式ガイド](https://api-docs.deepseek.com/guides/anthropic_api/)）
- LiteLLM: `deepseek/` プレフィックスで全モデル対応
- OpenRouter: DeepSeek 系 22 モデル

> **契約判断への影響**: Claude Code を DeepSeek バックエンドで動かせるなら、
> 「ハーネス用途は API 従量で代替できない」という前提が部分的に崩れる。
> [10_契約/02_AIフロンティア・バーベル戦略.md](../10_契約/02_AIフロンティア・バーベル戦略.md) の
> 8/7 判断に直接効くため、**実地検証の価値が高い**。

## 強み

- 価格が桁違いに安い（V4-Flash 入力 $0.14 / 1M）。cache hit で更に約 1/120
- 1M コンテキスト・384K 出力
- オープンウェイト（MIT・二次情報）でローカル実行の逃げ道がある
- Anthropic 互換 API により Claude Code 資産をそのまま流用できる

## 弱み

- **API 入力の学習除外が公式に明言されていない**（最大の弱み）
- データ保存先が中国固定でリージョン選択不可
- 各国政府機関での利用禁止事例が多く、業務・受託案件で使えない場面がある
- 公式 CLI / MCP の提供状況が不明
- ベンチはベンダー自己申告のみ

## 得意用途

- 大量生成・並列ワーカー（コスト優位が最も効く）
- 一般的なコード生成・リファクタ案・要約
- 反復の多い処理（cache hit が効く）

## 苦手用途

- **秘匿情報を含む処理**（規約リスク）
- 受託・業務案件で顧客データを扱う処理
- 規制の影響を受ける組織向けの成果物生成

## 黒澤用途

- **一般 LLM 処理の主力**（現行運用）
- Open WebUI ＋ LiteLLM 経由で日常利用（2026-07-20 実測で到達可能）
- バーベル戦略の第3レグ（API 従量）の中核
- 秘匿寄りの処理は Ollama へ回す
