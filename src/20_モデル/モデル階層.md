## 高速追従者の構造（2026-07-20 追加）

**DeepSeek と Kimi は、フロンティアを追う速度に構造的なブレーキが存在しない。**

両社に共通するのは次の3点で、これが追従を止められない理由になっている。

```text
オープンウェイト公開  → 蒸留・再学習を外部から阻止できない
低価格攻勢            → フロンティア価格に対して桁で下を取る
規約の緩さ            → 学習データ確保の制約が西側より小さい
```

| | DeepSeek | Kimi |
|---|---|---|
| 能力（独立評価） | SWE-bench Verified 80.6%（自己申告） | **AA Index 57**（Fable 5=60、Sol=59 に次ぐ・オープンウェイト最上位） |
| ウェイト公開 | ✅ MIT（二次情報） | ✅ Modified MIT（K3 は 07-27 予定） |
| 入力単価 /1M | **$0.435** | $3.00 |

**Anthropic・OpenAI 側に、この追従を止める法的・技術的手段は存在しない。**
モデル重みが公開され、API 経由の出力から蒸留が可能である以上、
フロンティアの優位は「先行期間の長さ」でしか表現されない。

### 契約設計への含意

この非対称は今後も続く前提で設計する。

```text
フロンティアの優位が時間とともに減価する
  → 高額サブスクへの固定は不利になっていく
  → 第3レグ（API 従量）の相対価値が上がり続ける
  → 8/7 の降格判断は「今回だけの節約」ではなく方向性
```

→ [10_契約/02_AIフロンティア・バーベル戦略.md](../10_契約/02_AIフロンティア・バーベル戦略.md) の
「高額固定費の二重化を避ける」という核心は、この構造によって時間とともに正しさを増す。

**ただし能力評価と規約適格性は分けて扱う**（下記2社の台帳を参照）。
追従が速いことと、業務データを渡してよいことは別問題。

- [cn-deepseek.md](../21_サービス/cn-deepseek.md) — 能力A・規約は秘匿不可
- [cn-kimi.md](../21_サービス/cn-kimi.md) — 能力フロンティア圏内・規約は秘匿不可

## 原則

- 高性能モデルを能力の中心に置かず、**通常処理は安価なモデルに任せ、失敗時・高影響時・検証不能時だけ上位モデルを呼ぶ**。
- プロバイダーリスク（政府規制・提供停止）を評価に含める。単一フロンティアモデルへの固定はしない（Fable 5 一時停止の教訓）。

この原則は [02_AIフロンティア・バーベル戦略.md](../10_契約/02_AIフロンティア・バーベル戦略.md) と同型であり、
[reasoning-orchestrator の conditional premium gate](../11_活用戦略/AI-Model%20API活用戦略.md) として実装されている。
